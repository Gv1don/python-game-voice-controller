# python-game-voice-controller
Голосовое управление играми через Python.
Программа слушает голосовые команды и эмулирует нажатия клавиш клавиатуры.

## Возможности
- Поддержка русского языка
- Настраиваемая карта команд
- Работа в любых играх без модификации клиента

## Установка
```bash
git clone https://github.com/Gv1don/python-game-voice-controller.git
cd python-game-voice-controller
